结论很清楚：**联通和移动方向晚高峰能跑满或接近跑满 1Gbps 端口，电信方向平均只有 250–450Mbps**，波动也更大。

这里要说明一处资料分歧：另一份 2025 年 12 月的第三方测评按运营商给新加坡排位时，认为联通方向「新加坡上行断流比较严重」，与上面那份晚高峰数据结论相反。两次测试的机型、节点、时段都不同，所以稳妥的说法是——移动方向普遍好评，联通多数实测表现好但存在争议，电信方向一致偏弱。如果你访客里北方电信占比高，香港节点会更合适。

**需要原生 IP 做特定业务**。SIN Pulse 用的是机房 IP 段，非原生广播，某些对 IP 归属敏感的场景可能受限。
